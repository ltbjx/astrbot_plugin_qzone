## 一分钟版本

1. 服务器上 **不需要**登录 QQ（纯 Cookie 模式），不会挤掉你自己的 QQ
2. 拿到 QQ空间 Cookie，填进 `qzone_cookie`
3. **确认 `trigger.like_use_http_key = true`** ← 关掉点赞就会静默失效
4. `like_only = true` 只点赞不评论，`like_cron = 0 */2 * * *` 每两小时一次
5. 用 `tools/qzone_check.py --list` 确认赞真的点上了，不要只信日志
