## 1. `core/scheduler.py` — 新增 `AutoLike` 任务 + `like_only`

**为什么**：上游的自动点赞**挂在自动评论任务里**：

```python
posts = await self.service.query_feeds(pos=0, num=20, no_self=True, no_commented=True)
for post in posts:
    await self.service.comment_posts(post)      # ← 先用 LLM 生成评论并发表
    if self.cfg.trigger.like_when_comment:
        await self.service.like_posts(post)     # ← 评论成功后才点赞
```

两个问题：
1. 只想点赞，就会连带**给好友动态挨个评论**（社交风险）；
2. 评论依赖 LLM，**评论一抛异常，后面的点赞就被 `except` 跳过** —— LLM 没配好 = 点赞完全不工作。

**改动**：新增独立的 `AutoLike` 定时任务。

```python
class AutoLike(AutoRandomCronTask):
    def __init__(self, config, service, sender):
        super().__init__("AutoLike", config.trigger.like_cron, config.timezone,
                         config.trigger.like_offset)
        self._store_path = Path(config.data_dir) / "liked_tids.json"
        self._liked: list[str] = self._load_liked()

    async def do_task(self):
        posts = await self.service.query_feeds(pos=0, num=num, no_self=True)
        for post in posts:
            if post.tid in self._liked:          # ← 本地去重
                continue
            await self.service.like_posts(post)
            self._liked.append(post.tid)
            await asyncio.sleep(random.randint(delay_min, delay_max))   # ← 防风控
        self._save_liked()
```

特点：
- **只点赞、不评论、不调 LLM**
- 已点赞的 `tid` 落盘去重（保留最近 2000 条）
- 每条之间随机等待 8~20 秒
- 不传 `no_commented`，避免为每条动态额外请求详情接口

同时给 `AutoComment.do_task()` 加了开头短路：

```python
if getattr(self.cfg.trigger, "like_only", False):
    logger.info("[AutoComment] like_only 已开启，跳过本轮自动评论")
    return
```


## 3. `core/qzone/api.py` — `http://` unikey 开关（**核心修复**）

```diff

+    # 本地补丁：点赞接口的 unikey/curkey 必须是 http:// 协议

```

```diff

+            self.BASE_URL_HTTP
```

## 6. `core/qzone/session.py` + `model.py` + `config.py` — 手工 Cookie 模式

`session.py`：Cookie 优先取配置，取不到才回落到 NapCat（`get_cookies`），并兼容直接粘贴整行 `Cookie: xxx`：

```python
cookies_str = str(getattr(self.cfg, "qzone_cookie", "") or "").strip()
if cookies_str:
    logger.debug("使用配置中的手工 QQ空间 Cookie")
else:
    if not self.cfg.client:
        raise RuntimeError("既没有配置 qzone_cookie，也没有可用的 CQHttp 实例（NapCat）")
    payload = await self.cfg.client.get_cookies(domain=self.DOMAIN)
    ...
```

`model.py`：把浏览器 Cookie 里除 `uin`/`skey`/`p_skey` 之外的字段也原样带上，提高接口成功率。

## 如何回滚到上游行为

1. `like_only` 设为 `false`
2. `qzone_cookie` 清空（走 NapCat）
3. `like_cron` 留空（关掉 `AutoLike` 任务）
4. `like_use_http_key` 设为 `false`（**不建议**，会重新变成假成功）

## 如何把补丁应用到更新的上游版本

```bash
git remote add upstream https://github.com/Zhalslar/astrbot_plugin_qzone
git fetch upstream
git checkout -b my-fork upstream/main
git apply patches/fork-vs-upstream.patch    # 可能有冲突，按提示手工合并
```

> `core/qzone/client.py`、`core/scheduler.py`、`core/service.py` 三处是最容易被上游重构碰到的地方，冲突时优先保留本 Fork 的修复语义。
