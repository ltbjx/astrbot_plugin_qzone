# 04 · 常见问题（FAQ）

## 一、点赞相关

### Q1. 日志明明写着「已点赞」，为什么空间里没有我的赞？

**先跑这个工具看真实状态**（这是唯一可信的判据）：

```bash
export QZONE_COOKIE='你的Cookie'
python3 tools/qzone_check.py --list
```

- 输出全是 `❌ 未赞 islike=0` → **赞没点上**。检查配置 `trigger.like_use_http_key` 是否为 `true`
  （`https://` 拼 `unikey` 时接口会返回 `succ` 但服务端忽略，这是最隐蔽的坑）
- 输出是 `✅ 已赞 islike=1` → 点赞正常，浏览器强刷（`Cmd/Ctrl+Shift+R`）或换客户端再看

详见 [03 · 点赞失效根因报告](03-点赞失效根因报告.md)。

### Q2. 为什么我自己发的说说从来没被点赞？

**这是设计如此。** 本插件点赞的是**好友动态流**里的动态，并且会主动排除自己的帖子（`no_self=True`）。

给自己的说说点赞没有意义，所以不做。想验证功能是否正常，请用 `tools/qzone_check.py --like-latest`，或者看好友的最新动态。

### Q3. 会不会重复点赞同一条动态？

不会。已成功点赞的 `tid` 会记在 `liked_tids.json` 里，每轮跳过。

> 注意：**只有成功点赞才会记录**（本 Fork 修复了「失败也记成功」的问题）。如果你要重新点一遍，删掉这个文件。

### Q4. 点赞太频繁会不会被封号？

会有风险，所以请保守设置。默认参数（每 2 小时、每次最多 20 条、每条间隔 8~20 秒随机）已经比较克制。**不要**把间隔压到几分钟。

另外：
- `like_offset` 别设成 0（整点触发特征太明显）
- 不要拿它去刷陌生人

### Q5. 能不能只点赞某几个人？

上游代码里没有按人过滤点赞的配置。可以改 `core/scheduler.py` 的 `AutoLike.do_task()`，在循环里按 `post.uin` 过滤。欢迎提 PR。

## 二、Cookie 相关

### Q6. Cookie 多久会过期？

不一定，通常**几天到几周**。`p_skey` / `skey` 在浏览器里是会话级 Cookie，浏览器关掉后服务端会话一般还能撑一段时间。

**过期表现**：日志出现

```
登录状态失效，请重新登录后重试
```

**处理**：重新复制一次 Cookie，填回 `qzone_cookie`，重启 AstrBot。

### Q7. 为什么 `document.cookie` 复制出来的不含 `p_skey`？

因为 `p_skey` 是 **HttpOnly**，JS 读不到。必须：
- 从 DevTools → Network → 请求头里的 `cookie:` 拿，或
- 从 DevTools → Application → Cookies 面板拿

### Q8. 用了 Cookie 模式，服务器还需要装 NapCat 吗？

**不需要。** 纯 Cookie 模式下插件完全通过 HTTP 调 QQ空间接口，服务器上不需要任何 QQ 客户端。

好处：不会把你本机 / 手机的 QQ 挤下线。（NapCat 是「电脑端」登录，同一个号不能同时登两台电脑。）

### Q9. 服务器上能不能同时用 Cookie 和 NapCat？

可以，但没必要 —— `qzone_cookie` 填了就用它，NapCat 只在 Cookie 为空时兜底。

## 三、Cookie 模式 vs NapCat 模式

| 问题 | 纯 Cookie | NapCat |
|---|---|---|
| 服务器要登 QQ 吗 | 不用 | 要 |
| 挤掉本机 QQ | 不会 | **会** |
| 挤掉手机 QQ | 不会 | 不会 |
| 凭据过期 | 需重新复制 Cookie | 掉线需重新扫码 |
| 能收命令 / 群聊互动 | ❌ 没有 QQ 连接，收不到消息 | ✅ |
| 能发说说 / 表白墙 | 代码支持，但没有触发入口 | ✅ |

## 四、任务与日志

### Q10. 日志出现 `Run time of job ... was missed by 0:00:01` 之后就没动静了？

这是**上游的一个严重 bug**，会导致任务链永久断掉、点赞静默失效。
本 Fork 已修（`misfire_grace_time=3600`）。如果你用的是上游版本，重启 AstrBot 可临时恢复，但还会再犯。

### Q11. 怎么看插件日志？

```bash
docker logs -f astrbot | grep -E "AutoLike|已点赞|点赞失败"
```

非 Docker 部署就看 AstrBot 控制台输出。

### Q12. 怎么临时加快频率来验证？

把 `like_cron` 设成 `* * * * *`、`like_offset` 设成 `0`，重启 AstrBot，等一分钟。验证完记得改回去。

## 五、安装与依赖

### Q13. 报 `ModuleNotFoundError: No module named 'json5'`（或 `PIL`、`apilmoji`）

依赖没装。：

```bash
docker exec astrbot pip install -i https://pypi.tuna.tsinghua.edu.cn/simple \
    Pillow json5 "apilmoji[tqdm]>=0.3.0,<1.0.0"
docker restart astrbot
```

### Q14. `pip install apilmoji[tqdm]` 提示 `does not provide the extra 'tqdm'`

只是警告，包本身已经装上了，可以忽略。

### Q15. 服务器拉不动 GitHub 怎么办？

- 用国内镜像克隆（如 `gh-proxy`、Gitee 镜像）
- 或者本地 `git clone` 后打包上传：`tar czf p.tgz --exclude=.git astrbot_plugin_qzone` → `scp` → 服务器解压到插件目录

## 六、合规与安全

### Q16. 这算违规吗？

本插件是**非官方第三方工具**，通过你本人的登录态访问你自己的 QQ空间，属于"自动化你自己的账号操作"。
但任何自动化访问都可能触发平台风控，**请自担风险**，并保持低频、只对好友使用。

### Q17. Cookie 泄露会怎样？

Cookie 等同于你 QQ空间的登录凭证，拿到它的人可以以你的身份操作空间（看私密内容、发说说、删说说等）。因此：

- **绝对不要**提交到 Git（`.gitignore` 已排除相关文件）
- **绝对不要**发到群里 / 贴到公开 Issue 里（提 Issue 记得打码）
- 服务器上的配置文件权限收紧：`chmod 600 data/config/astrbot_plugin_qzone_config.json`
- 怀疑泄露：去 QQ空间网页版退出登录，Cookie 立即失效
