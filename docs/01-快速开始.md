## 前置条件

| 项 | 要求 |
|---|---|
| AstrBot | 4.x（实测 4.29.0；上游标注 3.4+） |
| Python | 3.10+ |
| 依赖 | `Pillow`、`json5`、`apilmoji[tqdm]` |
| 网络 | 服务器需能访问 `user.qzone.qq.com`、`h5.qzone.qq.com`（国内机器都没问题） |

安装依赖（国内建议走清华源）：

```bash
pip install Pillow json5 "apilmoji[tqdm]>=0.3.0,<1.0.0" -i https://pypi.tuna.tsinghua.edu.cn/simple
```

Docker 部署的 AstrBot：

```bash
docker exec astrbot pip install -i https://pypi.tuna.tsinghua.edu.cn/simple \
    Pillow json5 "apilmoji[tqdm]>=0.3.0,<1.0.0"
```

## 两种运行模式怎么选

| | 纯 Cookie 模式 | NapCat 模式 |
|---|---|---|
| 服务器上要不要登录 QQ | **不用** | 要（扫码） |
| 会不会挤掉你本机 QQ | **不会** | **会**（NapCat 是「电脑端」登录，同号不能同登两台电脑） |
| 手机 QQ | 不受影响 | 不受影响 |
| 能用的功能 | 自动点赞（及所有走空间 HTTP 接口的功能） | 全部（含群聊互动、命令、发说说、表白墙） |
| 凭据 | 手工复制一次 Cookie | NapCat 自动提供 |
| 凭据寿命 | 几天～几周会过期 | 掉线为止 |

> **只想自动点赞 → 选纯 Cookie 模式。** 这是本 Fork 专门强化的场景。

## 方式一：纯 Cookie 模式（推荐）

### 1. 安装插件

```bash
cd /AstrBot/data/plugins
git clone https://github.com/YOUR_GITHUB_USERNAME/astrbot_plugin_qzone
```

装完重启 AstrBot。若日志出现：

```
Plugin astrbot_plugin_qzone (v3.2.0) ...
[AutoLike] 已启动，任务周期：0 */2 * * *，偏移范围：±900 秒
```

说明插件已加载、`AutoLike` 任务已注册。

### 2. 获取 QQ空间 Cookie

**方法 A：浏览器 DevTools（最通用）**

1. 打开 `https://user.qzone.qq.com/<你的QQ号>`，确认已登录
2. `F12` → **Network / 网络** → `F5` 刷新
3. 在筛选框输入 `qzone`，点任意一条发往 `user.qzone.qq.com` 的请求
4. 右键该请求 → **Copy → Copy as cURL (bash)**
5. 保留下一步要用到的 `cookie` 值

**方法 B：DevTools 的 Application 面板（不用找请求）**

`F12` → **Application / 应用程序** → 左侧 **Storage → Cookies → https://user.qzone.qq.com** → 右侧表格全选复制。
需要的关键行：`p_skey`、`skey`、`uin`（`uin` 的值形如 `o123456789`）。

**方法 C：QQ 客户端内嵌浏览器（最省事）**

用 QQ 客户端里的浏览器打开你的空间。QQ 客户端那套浏览器的 Cookie 库是**明文存储**的，可以直接读出来 —— 不需要手抄。
（macOS 上的位置形如 `~/Library/Containers/com.tencent.qq/Data/Library/Application Support/QQ/Partitions/qq-browser-<QQ号>/Cookies`，SQLite 格式。）

> ⚠️ `p_skey` 是 **HttpOnly**，在控制台执行 `document.cookie` **取不到**，必须从请求头或 Application 面板拿。
> ⚠️ Cookie 里**必须同时有 `p_skey` 和 `uin`**，缺一个插件会直接报「Cookie 中缺少合法 uin」。

### 3. 填写配置

AstrBot 面板 → 插件 → **QQ空间** → 配置：

```jsonc
{
  "qzone_cookie": "uin=o123456789; skey=@xxxx; p_skey=xxxx; ...",  // ← 粘贴整串
  "trigger": {
    "like_only": true,          // 只点赞，不评论
    "like_cron": "0 */2 * * *", // 每 2 小时一次；留空 = 关闭
    "like_offset": 900,         // 时间随机浮动 ±15 分钟
    "like_num": 20,             // 每轮最多 20 条
    "like_delay_min": 8,
    "like_delay_max": 20,
    "like_use_http_key": true,  // ★ 必须为 true，否则点赞静默失效
    "comment_cron": "",         // 纯点赞模式下关掉
    "publish_cron": ""
  }
}
```

### 4. 立即验证（别等 2 小时）

把 `like_cron` 临时改成 `* * * * *`、`like_offset` 改成 `0`，重启 AstrBot，一分钟内就能看到结果：

```bash
docker logs --since 3m astrbot 2>&1 | grep -E "已点赞|本轮检查"
```

验证完记得改回 `0 */2 * * *` / `900`。

## 方式二：NapCat 模式

1. 确认 NapCat 已登录 QQ，且 AstrBot 里配好 `aiocqhttp` 平台（反向 WS）
2. **`qzone_cookie` 留空** —— 插件会自动通过 OneBot 的 `get_cookies` 取 `user.qzone.qq.com` 的 Cookie
3. 其余配置同方式一

NapCat 的反向 WS 配置（NapCat 侧）示例：

```json
{
  "enable": true,
  "name": "astrbot",
  "url": "ws://astrbot:6199/ws",
  "token": "<与 AstrBot 里 ws_reverse_token 一致>",
  "messagePostFormat": "array",
  "heartInterval": 30000,
  "reconnectInterval": 30000
}
```

AstrBot 侧（`data/cmd_config.json`）：

```json
"platform": [
  {
    "id": "napcat",
    "type": "aiocqhttp",
    "enable": true,
    "ws_reverse_host": "0.0.0.0",
    "ws_reverse_port": 6199,
    "ws_reverse_token": "<和上面一致>"
  }
]
```

> ⚠️ 再次提醒：这一步会让服务器以「电脑端」登录你的 QQ，**你本机 QQ 会被挤下线**。

## 安装后的自检清单

```bash
# 1. 插件是否加载
docker logs astrbot 2>&1 | grep -E "Plugin astrbot_plugin_qzone|AutoLike.*已启动"

# 2. 任务是否在跑（等一轮后看）
docker logs astrbot 2>&1 | grep "本轮检查"

# 3. 点赞是否真的生效（最权威）
export QZONE_COOKIE='你的Cookie'
python3 tools/qzone_check.py --list
```

判断标准：

| 现象 | 含义 | 处理 |
|---|---|---|
| `Plugin ... 已加载` + `[AutoLike] 已启动` | 插件与任务正常 | 继续 |
| 日志「Cookie 中缺少合法 uin」 | Cookie 复制不全 | 重新复制，确认含 `uin=o...` |
| 日志「登录状态失效」 | Cookie 过期 | 重新复制一次 |
| `qzone_check.py --list` 全是 `islike=0` | 点赞没点上 | 确认 `like_use_http_key=true` |
| 日志出现 `was missed by` 之后没了 | 任务链断掉 | 重启 AstrBot（本 Fork 已修，正常不会出现） |
