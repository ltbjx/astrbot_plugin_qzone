# 06 · 部署到服务器

这里给出一个**最小可用**的部署方案：只用 Docker 跑 AstrBot（不跑 NapCat），插件走纯 Cookie 模式自动点赞。

---

## 架构

```
你的浏览器（复制一次 QQ空间 Cookie）
        │
        ▼
服务器 /opt/qzone-bot/
├── docker-compose.yml
└── astrbot/data/
    ├── config/astrbot_plugin_qzone_config.json   ← Cookie 填这里
    └── plugins/astrbot_plugin_qzone/             ← 本插件
        │
        ▼
   AstrBot 容器（面板 6185）
        └── AutoLike 任务：每 2 小时拉一次好友动态流并点赞
```

**服务器上没有任何 QQ 客户端**，因此不会影响你本机 / 手机上的 QQ。

---

## 资源需求

| 项 | 最低 | 推荐 |
|---|---|---|
| 内存 | 512 MB | 1 GB |
| 磁盘 | 3 GB（AstrBot 镜像 1.9 GB） | 5 GB |
| CPU | 1 核 | 2 核 |

## 一、部署

### 1. 目录与编排文件

```bash
mkdir -p /opt/qzone-bot/astrbot/data/plugins
cd /opt/qzone-bot
```

`docker-compose.yml`：

```yaml
services:
  astrbot:
    image: soulter/astrbot:latest
    container_name: astrbot
    restart: always
    environment:
      - TZ=Asia/Shanghai
    ports:
      - "6185:6185"      # 面板
    volumes:
      - ./astrbot/data:/AstrBot/data
```

启动：

```bash
docker compose up -d
docker compose ps
```

### 2. 安装插件与依赖

```bash
cd /opt/qzone-bot/astrbot/data/plugins
git clone https://github.com/ltbjx/astrbot_plugin_qzone

docker exec astrbot pip install -i https://pypi.tuna.tsinghua.edu.cn/simple \
    Pillow json5 "apilmoji[tqdm]>=0.3.0,<1.0.0"

docker restart astrbot
```

> 服务器拉不动 GitHub 时：本地打包 `tar czf p.tgz --exclude=.git astrbot_plugin_qzone` 再 `scp` 上传解压。

### 3. 确认插件加载

```bash
docker logs astrbot 2>&1 | grep -E "Plugin astrbot_plugin_qzone|AutoLike"
```

期望输出：

```
[Core] Loading plugin astrbot_plugin_qzone ...
Plugin astrbot_plugin_qzone (v3.2.0) ...
[AutoLike] 已启动，任务周期：0 */2 * * *，偏移范围：±900 秒
```

## 二、配置

### 方式 A：面板（推荐）

浏览器打开 `http://<服务器IP>:6185`，默认账号密码都是 `astrbot`（**首登强制改密码**）。
→ 插件 → QQ空间 → 配置 → 填 `qzone_cookie` 与 `trigger.like_*`。

### 方式 B：直接改配置文件

```bash
nano /opt/qzone-bot/astrbot/data/config/astrbot_plugin_qzone_config.json
chmod 600 /opt/qzone-bot/astrbot/data/config/astrbot_plugin_qzone_config.json   # 里面有 Cookie
```

关键字段：

```jsonc
{
  "qzone_cookie": "uin=o123456789; skey=@xxxx; p_skey=xxxx; ...",
  "trigger": {
    "like_only": true,
    "like_cron": "0 */2 * * *",
    "like_offset": 900,
    "like_num": 20,
    "like_delay_min": 8,
    "like_delay_max": 20,
    "like_use_http_key": true,
    "comment_cron": "",
    "publish_cron": ""
  }
}
```

改完 `docker restart astrbot`。

> 如果面板里保存过配置，文件可能是带 BOM 的，用 `encoding="utf-8-sig"` 读写比较稳。

## 三、验证

```bash
# 临时加速：like_cron 改成 "* * * * *"、like_offset 改成 0，重启后等 1 分钟
docker logs --since 3m astrbot 2>&1 | grep -E "已点赞|本轮检查"
```

```
已点赞 → 某某
本轮检查 5 条动态，新点赞 5 条，跳过已赞 0 条，去重库共 5 条
```

再用工具做**独立复核**（不要只信日志）：

```bash
docker exec astrbot python3 /AstrBot/data/plugins/astrbot_plugin_qzone/tools/qzone_check.py --list \
  --cookie "$(python3 -c "import json;print(json.load(open('/opt/qzone-bot/astrbot/data/config/astrbot_plugin_qzone_config.json',encoding='utf-8-sig'))['qzone_cookie'])")"
```

看到 `✅ 已赞 islike=1` 才算真的成功。

## 四、云服务器安全组 / 防火墙

需要在云厂商控制台放行入站端口：

| 端口 | 用途 | 是否必须 |
|---|---|---|
| `6185` | AstrBot 面板 | 建议放行（否则只能改文件配置） |
| `22` | SSH | 必须 |

若用 NapCat：还需要 `6099`（WebUI）。

服务器本机防火墙（firewalld/ufw）也要确认没挡：

```bash
systemctl is-active firewalld        # CentOS
firewall-cmd --list-ports
ufw status                           # Ubuntu
```

## 五、运维命令

```bash
cd /opt/qzone-bot

docker compose ps                                    # 状态
docker logs -f astrbot                               # 实时日志
docker logs astrbot 2>&1 | grep -E "AutoLike|已点赞"  # 只看点赞
docker compose restart astrbot                       # 重启（改完配置）

# 备份（含 Cookie 与去重记录，注意保密）
tar czf qzone-backup-$(date +%F).tgz astrbot/data/config astrbot/data/plugin_data
```

## 六、定时健康检查（可选）

Cookie 过期是**静默**的（点赞停了但不会主动通知你）。可以加一个 cron 定期检查：

```bash
cat > /opt/qzone-bot/check.sh <<'EOF'
#!/bin/bash
# 每天 9 点检查一次：最近一轮点赞是否有失败迹象
cd /opt/qzone-bot
if docker logs --since 24h astrbot 2>&1 | grep -q "登录状态失效"; then
    echo "[$(date)] QQ空间 Cookie 已失效，请重新获取" >> /var/log/qzone-health.log
fi
EOF
chmod +x /opt/qzone-bot/check.sh
echo "0 9 * * * /opt/qzone-bot/check.sh" | crontab -
```

> 想做成主动通知（邮件 / 飞书 / 企业微信机器人），在 `check.sh` 里加一行 `curl` 即可。

## 七、常见部署问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板打不开 | 安全组没放行 6185 | 控制台加入站规则 |
| `docker pull` 超时 | Docker Hub 拉不动 | 配镜像加速，或换国内源 |
| 容器反复重启 | 内存不足（OOM） | `docker stats` 看；加内存或清插件 |
| 插件加载报缺依赖 | 没装 `json5`/`Pillow`/`apilmoji` | 见「安装插件与依赖」 |
| 日志 `Cookie 中缺少合法 uin` | Cookie 复制不全 | 重新复制，确认含 `uin=o...` |
| 点赞成功但空间没有 | `like_use_http_key` 没开 | 设为 `true`，见 [03](03-点赞失效根因报告.md) |
